# 依赖说明（重要）
# 1) 本环境请使用 Python 3.11 ~ 3.12 创建 venv
# 2) torch/torchvision 不要放在本文件里装（pip 会优先取清华源的 CPU 版），单独执行：
#    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
# 3) 知识图谱实体/关系抽取使用 PaddleNLP UIE(uie-base)，但因 paddlenlp 在 Windows
#    强制 protobuf==3.20.2，与本环境 pymilvus(需 protobuf>=5)不可共存，故 UIE 不装在本
#    venv，而是拆到独立的 uie_service/（独立 venv + HTTP 微服务，CPU 推理）。
#    本环境的 knowledge/utils/uie_util.py 只是调用该服务的 HTTP 客户端。
#    注：transformers/accelerate 仍保留，供 sentence-transformers/FlagEmbedding 使用。
# 4) 推荐安装顺序（避免 mineru 巨大依赖树引发 pip 回溯卡死）：
#    a. pip install -U pip
#    b. 上面第 2 步的 torch / torchvision
#    c. pip install "mineru[all]" -i https://pypi.tuna.tsinghua.edu.cn/simple
#    d. pip install FlagEmbedding -i https://pypi.tuna.tsinghua.edu.cn/simple
#    e. pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
